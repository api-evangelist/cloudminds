# CloudMinds / Dataa Robotics

> Cloud-robotics company founded 2015 (Beijing + formerly Santa Clara/Irvine), backed by SoftBank and
> Foxconn, now operating as Dataa Robotics (达闼机器人). Builds cloud-connected service robots and the
> HARIX cloud AI robot brain. There is no public REST API and no OpenAPI. The machine-readable contract
> is gRPC/protobuf3 — 14 services and 88 RPCs covering robot control, navigation, configuration,
> text-to-speech, skill dispatch, speech recognition, vision recognition and NLU — shipped as compiled
> descriptors inside the first-party "harix" Python SDK on PyPI. That SDK's last release was 2020-02-17,
> and the HARIX RDK developer portal does not answer from outside China.

## Notes for agents

- There is no callable public endpoint. The SDK takes the gRPC target as a caller-supplied parameter; CloudMinds documents no default host, so integration requires a deployment-specific address obtained from the vendor.
- Channels are plaintext. The first-party SDK never configures TLS credentials.
- No idempotency key exists. Mutating RPCs — including Move, EmergencyStop, RebootRobot and ShutdownRobot — are physical-consequence operations that are not safe to retry blindly.
- Errors return inside a successful response as common.CommonRspInfo.err_code. No public registry of those codes exists, so error handling cannot be written against a known vocabulary.
- The legacy domain cloudminds.com does not answer. Anything citing it as a live surface is stale.
- CloudMinds Technology Inc. and affiliates were added to the U.S. BIS Entity List in May 2020.
